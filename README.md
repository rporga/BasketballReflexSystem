# Basketball Reflex System

NBA matchup intelligence and analytical dashboard. This project starts with an interactive prototype using **synthetic demonstration data**, not real NBA statistics or validated betting predictions.

## MVP
- Matchup comparison and illustrative model probabilities
- Quarter-by-quarter scoring profiles
- Hypothetical player absence scenarios
- Manual odds comparison (no live sportsbook connection)

## GitHub Pages
When `index.html` is present, go to **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root)**. GitHub Pages will publish at `https://rporga.github.io/BasketballReflexSystem/` once enabled and deployed.

## Next
Integrate licensed NBA data through secure APIs, store and process historical games, train and backtest a calibrated prediction model, and validate injury scenarios against actual roster availability.

No subscriptions or payment features are included. API keys must never be published in front-end code.
